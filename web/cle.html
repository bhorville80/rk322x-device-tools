Premier demarrage

su -c 'sh /mnt/media_rw/*/deploy.sh INSTALL'
installe les outils dans /data/scripts + liens /data/bin (backup auto). Ensuite tout se pilote depuis la box : commande deploy ou amorce.

Contenu de la cle

  • deploy.sh - installeur / point d'entree (INSTALL, PKG, RESTORE, EXPOSE, STOP, SEND_LOGS, VERSION, STATUS, CLEAN)
  • AMORCE - aide-memoire 2 etapes
  • rk322x-tools_v*.dpk (+.sha256) - paquet d'installation (deploy PKG)
  • config/device.conf - profil cible (reseau, ssh, services) - voir la copie servie
  • scripts/ - tous les outils + core/
  • server/ - httpd 8000, control 8080, gui 8081, watcher USB
  • manifests/ - traces d'installation (current/history)
  • log/ - collectes SEND_LOGS, exec, gui_shots, state_last.txt
  • admin/ - outillage PC (provision, set_box_time, logpull, vitals_history)
  • index/cle/commandes/metriques.html - ce panneau web

Catalogue des outils (par fonction)

  • Bilan : amorce (etat + raccourcis), check_state (etat cible vs reel), selftest, conf_check (validation config), show_key
  • Materiel / inspection : inspect_all (global), inspect_system, device_info (puces par fonctionnalite), inspect_services, inspect_gui, inspect_display, inspect_remote, inspect_user, sd_inspect
  • Metriques : vitals (STATUS/WATCH/CSV), thermal (ECO/PERF), net_diag, sys_diag
  • Actions : hdmi ON|OFF, disable_wireless, field_mode ON|OFF|STATUS, cut_services (CUT/APPS/RESTORE), front_led, system_rw RW|RO, motd, media
  • Reseau / temps : set_network, set_time
  • Maintenance : deploy (INSTALL/PKG/RESTORE/CLEAN/VERSION/STATUS), sync_usb, rotate_logs
  • Serveurs : EXPOSE (httpd+gui+control+watcher), STOP, ssh_server (dropbear)

Serveurs exposes sur le reseau

  • 8000 HTTP - cette interface + fichiers de la cle (logs, config)
  • 8080 CONTROL - API commandes (token si server/token present)
  • 8081 GUI - affichage TV plein ecran, touches, screenshot
  • 5555 adb tcpip  |  2222 dropbear (si lance)
arret global : deploy STOP ou bouton correspondant page Commandes

Protection optionnelle par token. Tant que server/token n'existe pas sur la cle, l'API 8080 et la GUI 8081 sont ouvertes a tout le LAN. Pour les proteger :
deploy TOKEN ON (token aleatoire) ou deploy TOKEN MonSecret123, puis deploy STOP && deploy EXPOSE. Le panneau demandera la valeur une seule fois par navigateur (gardee en localStorage). Retrait : deploy TOKEN OFF.
